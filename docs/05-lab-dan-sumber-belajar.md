# 5. Lab Latihan Legal & Sumber Belajar

**Latih semua skill di sini — bukan di website orang.** Lab-lab ini memang dibuat untuk dihack,
jadi 100% legal dan aman untuk eksperimen sebebas-bebasnya.

---

## 🧪 Lab Latihan (legal, gratis/murah)

| Nama | Isi | Catatan |
|------|-----|---------|
| **PortSwigger Web Security Academy** | Lab interaktif per topik + teori | ⭐ Terbaik untuk pemula, **gratis** |
| **OWASP Juice Shop** | Aplikasi web sengaja rentan, banyak tantangan | Bisa dijalankan sendiri (Docker) |
| **TryHackMe** | Jalur belajar bertahap, ramah pemula | Ada gratis & berbayar |
| **Hack The Box (+ HTB Academy)** | Mesin & modul, lebih menantang | Cocok setelah paham dasar |
| **PentesterLab** | Latihan fokus per kerentanan | Berbayar sebagian |
| **DVWA** (Damn Vulnerable Web App) | App rentan klasik untuk latihan | Jalankan lokal |

> Mulai dari **PortSwigger Academy** + **Juice Shop**. Dua ini saja sudah cukup untuk berbulan-bulan belajar.

## 🎯 Platform Bug Bounty (program nyata — nanti, setelah siap)

| Platform | Catatan |
|----------|---------|
| **HackerOne** | Terbesar; lihat *Hacktivity* untuk belajar dari laporan nyata |
| **Bugcrowd** | Besar, ramah pemula, ada *VRT* (panduan severity) |
| **Intigriti** | Kuat di Eropa |
| **YesWeHack** | Global, banyak program publik |
| **VDP perusahaan** | Banyak perusahaan punya halaman `/.well-known/security.txt` atau `/security` |

Saat memilih program pertama: cari yang **publik**, **scope luas (ada wildcard `*.domain`)**,
**punya safe harbor**, dan **ramah pemula**.

## 📚 Bacaan & Referensi

- **OWASP Top 10** — daftar risiko keamanan web terpenting (wajib paham).
- **OWASP Testing Guide** / **Web Security Testing Guide (WSTG)** — metodologi detail.
- **PortSwigger blog & research** — penemuan teknik baru.
- **HackerOne Hacktivity** — laporan nyata yang sudah di-*disclose* (belajar dari yang sudah jago).
- **PayloadsAllTheThings** (repo GitHub) — kumpulan payload & teknik per kelas bug.

## 🎥 Format belajar

- Suka video → cari channel YouTube bug bounty / web security (banyak yang gratis & bagus).
- Suka baca → PortSwigger Academy + writeup di blog peneliti.
- Suka praktik → langsung kerjakan lab, baca teori saat mentok.

## 💬 Komunitas

Gabung komunitas (Discord/forum bug bounty) untuk tanya-jawab & tetap termotivasi.
Belajar bareng jauh lebih cepat daripada sendirian.

---

## Catatan untuk pemula

- **Jangan beli course mahal dulu.** Materi gratis (PortSwigger, OWASP, Juice Shop) sudah lebih
  dari cukup untuk level pemula–menengah.
- **Konsistensi > intensitas.** 1 jam sehari rutin kalahkan maraton seminggu sekali.
- **Dokumentasikan** apa yang kamu pelajari di `notes/`. Mengajar ulang diri sendiri = belajar terkuat.
